# Pre-alpha de comparación

Archivo de la implementación anterior al alcance vigente [00–08 v2](../../00_LEEME.md). Conserva HTML, JS, CSS y documentos históricos; sus funciones y pendientes no definen el objetivo final. Ejecutar desde la raíz con `npm run dev:legacy`.

Esta versión tiene PeerJS/CDNs, mapa único, enlaces Google y Snake experimental. No acredita las sesiones temporales de diez participantes ni la aceptación de la demo v2. No se importa ni se copia al build de `apps/web`.

**Arte reciente:** `assets/images` contiene también el piso, sillas, escritorios y referencia recién entregados, pendientes de integrar. El [inventario](../../docs/assets.md) los distingue de los recursos antiguos; conservar estos originales.
