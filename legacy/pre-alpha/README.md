# Pre-alpha de comparación

Archivo de la implementación anterior a las especificaciones 00–08. Conserva HTML, JS, CSS, assets y documentos históricos. Ejecutar desde la raíz con `npm run dev:legacy`.

Esta versión tiene PeerJS/CDNs, mapa único, enlaces Google y Snake experimental. No implementa las nuevas reglas de identidad, permisos o continuidad. No se importa ni se copia al build de `apps/web`.
